# OCR-Терминал

Electron-фронт для терминальной стойки OCR. Приложение показывает стартовый экран с согласием, экран камеры с рамкой паспорта, отправляет снимок в локальный OCR API и отображает распознанные поля для подтверждения или пересъёмки.

## Требования

- Node.js 20+
- OCR API на `http://127.0.0.1:8000`
- Фото-сканер или камера, доступная браузерному `getUserMedia`

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

## Проверка JavaScript

```bash
npm run check
```

## Конфигурация

Основные параметры вынесены в `config/default.json`:

- `apiBaseUrl` - адрес OCR API
- `window.startMode` - режим старта окна, по умолчанию `fullscreen`
- `window.fullscreen` - настоящий полноэкранный режим для терминала
- `window.kiosk` - kiosk-режим без обычного выхода из полноэкранного окна
- `pollIntervalMs` - интервал polling статуса задачи
- `maxFileSizeMb` - локальный лимит размера изображения
- `idleWarningMs` и `sessionTimeoutMs` - таймеры неактивности
- `camera` - предпочтительные параметры видеопотока

## Реализованный сценарий

1. Пользователь принимает согласие на обработку персональных данных.
2. Приложение открывает экран камеры и проверяет `/health`.
3. Пользователь делает снимок или выбирает тестовое изображение.
4. Фронт отправляет изображение в `POST /passprot` multipart-полем `image`.
5. Фронт берёт `job_id` из `data.meta.task.job_id`.
6. Фронт опрашивает `GET /jobs/{job_id}` до финального статуса из `data.meta.task.status`.
7. При `done` отображаются `data.passport` и метаданные OCR из `data.meta`.
8. Пользователь подтверждает данные или запускает пересъёмку.
9. При подтверждении или неактивности сессия очищается и возвращается на старт.
